# 乡音智旅微信小程序

## 项目介绍
乡音智旅是一款专注于本地旅游攻略和文化体验的微信小程序，为用户提供当地美景、旅游攻略、语音讲解等服务。

## 项目结构

```
xyzl/
├── app.js          # 全局应用逻辑
├── app.json        # 小程序配置文件
├── pages/
│   ├── index/      # 首页
│   │   ├── index.wxml
│   │   ├── index.wxss
│   │   └── index.js
│   ├── find/       # 发现页
│   │   ├── find.wxml
│   │   ├── find.wxss
│   │   └── find.js
│   └── mine/       # 个人主页
│       ├── mine.wxml
│       ├── mine.wxss
│       └── mine.js
└── README.md       # 项目说明
```

## 功能特点

### 首页
- 搜索栏：查找需要的攻略
- 轮播图：展示当地美景照片
- 标签栏：推荐、攻略、景点、历史
- 景点列表：展示热门景点和简介



### 个人主页
- 用户信息展示
- 功能模块：我的收藏、旅行攻略、我的交流
- 其他功能：设置、我的购买、客服中心、关于我们

## 如何使用

1. 打开微信开发者工具
2. 导入项目目录
3. 选择小程序项目类型
4. 填写AppID（如果没有可以使用测试号）
5. 点击「导入」按钮
6. 运行项目查看效果

## 技术栈
- 微信小程序原生框架
- WXML + WXSS + JavaScript
- Node.js + Express 后端服务
- MySQL 数据库存储
- 网络请求

## 注意事项
- 本项目已对接真实后端API，需要启动后端服务才能正常使用
- 图片资源使用了在线生成的图片
- 需要配置数据库连接信息
